## 1.1 — Absolute Basics
- `field` name comes first, colon, then value
- Quote string values that contain spaces, special characters, or are unclear
- Numeric values don't need quotes
- Boolean values: `true` or `false` (no quotes)
- Field names are case-sensitive
- Values are usually case-insensitive for text (depends on field mapping in Kibana)

**ALWAYS quote:**

- Strings with special characters
- Empty strings
- Boolean keywords if you want them literal

**DON'T need to quote:**
- Simple alphanumeric strings
- Numbers
- Dates in specific contexts

## 1.3 — Whitespace and Formatting

# SECTION 2: WILDCARD PATTERNS

## 2.1 — Asterisk Wildcard (`*`)
`*` matches zero or more characters. Wildcards MUST be inside quotes:

## 2.2 — Question Mark Wildcard (`?`)
`?` matches exactly one character.

## 2.3 — Asterisk as Existence Check
Bare `*` checks if a field exists:

## 3.3 — NOT
